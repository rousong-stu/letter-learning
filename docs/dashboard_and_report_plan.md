# 首页与成绩单改版开发计划

## 目标
在现有稳定版本上，新增展示型首页与成绩单导出能力，同时优化细节体验。首页需美观可视化，成绩单导出为精美 PDF，其他细节调整保证整体一致性。

## 功能范围
1. 首页数据展示（可视化）：学习进度、计划执行、当前单词书、AI 对话活跃度、短文生成情况、连续学习天数等。
2. 成绩单导出：在首页弹窗选择日期范围，生成 PDF 学习清单（统计卡片 + 图表/摘要）。
3. 细节优化：短文生成过场动画；首页排版/图片替换；站点名称/图标替换；移除页脚版权文案；学习设置页面两侧高度对齐；“AI 词汇短文”页 Tab 前加小图标。

## 后端改动建议
- 新增聚合接口（示例）：`GET /dashboard/summary?from=YYYY-MM-DD&to=YYYY-MM-DD`
  - 学习进度：单词掌握/学习/未学占比（user_word_book_words）
  - 计划执行：每日 quota vs 实际完成（user_word_books + user_word_book_words）
  - 短文：累计/最近 N 天生成数，最近一篇摘要（word_stories）
  - AI 对话：会话/消息按日计数（ai_chat_sessions/ai_chat_messages）
  - 当前单词书：名称、标签、已掌握/剩余（user_word_books + user_word_book_words）
  - 连续学习天数：基于 word_stories 的日期连续性
- 性能：为上述查询补充必要索引；如未来数据量大，再考虑“每日用户统计”冗余表（异步/定时更新）。
- 预留：接口返回可用于成绩单导出的同一套统计数据。

## 前端实现方案
### 首页
- 布局：顶部概要卡片（进度、今日进度、连续天数、AI 对话数）；中部图表（词汇掌握环形图、计划执行柱状、短文/对话折线）；侧边/下方卡片（当前单词书、最近短文摘要）。
- 数据：调用新的 `/dashboard/summary`（按日期范围或默认最近 7/30 天）。
- 视觉：统一色板/字体，替换主图，移动端自适应。

### 成绩单导出（前端版）
- 首页按钮 + 日期范围弹窗。
- 复用 summary 数据；用前端 PDF 库生成 PDF（封面、统计卡片、图表截图/矢量、简要明细）。
- 下载并提示生成中/错误。
- 如性能不足，再评估后端生成。

### 细节
- 短文生成：调用时显示过场动画/遮罩，完成或失败关闭。
- 首页：排版优化、主图替换。
- 站点名称/图标：更新 title、favicon、logo。
- 页脚：移除版权文案，保留容器待后续填充。
- 学习设置：左右高度对齐（CSS 调整）。
- AI 词汇短文 Tab：在 “AI对话/单词卡片/词典” 前加小图标（可用现有图标库）。

## 指标建议（首页显示）
- 词汇掌握占比：mastered/learning/unlearned（饼/环形图）。
- 计划执行：每日 quota vs 实际完成（柱状图，支持日期范围）。
- 短文：每日生成数 + 最近一篇摘要（折线 + 卡片）。
+- AI 对话活跃度：按日会话/消息数（折线/面积图）。
 - 当前单词书：名称、标签、已掌握/剩余词数（水平进度条）。
 - 连续学习天数：徽章或数字卡。

## 素材与文案
- 需要：站点名、favicon/logo、首页主图/插画、过场动画（GIF/Lottie）、Tab 小图标（或指定图标库）、想要的色板/字体（如不指定，将选一套统一方案）。
- 提供方式：将文件放入 `letter-learning-ui/src/assets/` 并告知路径，或提供下载链接/明确的设计方向。

## 阶段规划
1) 确认需求与素材：锁定指标口径、UI 风格、素材来源；确认是否采用前端 PDF 方案。  
2) 后端：实现 `/dashboard/summary` 聚合接口，补索引，自测。  
3) 前端：首页布局与图表、成绩单导出流程、细节动画与样式替换。  
4) 联调与验收：本地/测试环境验证接口与展示，检查性能与交互。  
5) 上线：打包前端 dist 上传、重启后端，线上回归。
