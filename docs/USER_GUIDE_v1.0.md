# 网站使用说明（正式版 v1.0）

## 面向用户的快速开始
1. 打开网站首页（Nginx 入口，默认根路径）。
2. 登录/注册
   - 输入用户名、密码、验证码后登录。
   - 勾选“记住密码”可保存下次登录。
3. 登录成功后默认进入首页看板，查看学习概览。
4. 点击左侧菜单“开始学习” → “Lumilyx短文伴学”进入学习页面。

## Lumilyx 短文伴学
- 今日词包记忆任务
  - 显示今日词汇列表，可点击任意单词，自动切换到“词典”并查询。
  - 短文正文中的英文词也可点击，自动查询词典。
- 再学一篇
  - 每日默认限制 2 篇；超出时会弹窗提示，可选择“仍然继续学习”继续生成。
  - 生成过程中显示加载动画。
- 侧边卡片
  - Lumilyx：对话区域，可与 AI 对话。
  - 单词卡片：显示学习中的单词详情；支持滚动查看。
  - 词典：查询结果展示，点击单词会自动切换到此 Tab。

## 首页看板
- 显示学习进度、今日完成、连续学习天数、AI 对话轮次等指标。
- 刷新后可获取最新数据；更新学习计划后全站刷新以确保数据最新。

## 学习设置
- 配置学习计划、调整单词书；上传单词书入口已移到“学习设置”下（需要管理员权限）。
- 更新计划后，建议刷新页面或重新进入确保新计划生效。

## 账号与安全
- 登录使用验证码校验。
- 如需退出登录，可在右上角用户菜单中选择“退出”。

## 常见问题
- 生成短文超过 2 篇：弹窗确认继续即可；否则第二天自动重置。
- 点击单词词典空白：已修复；若仍遇到，请刷新页面再试。
- 词典查询失败：检查网络或稍后重试；若仍失败，请联系管理员。
